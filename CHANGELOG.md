# Changelog

## 0.1.0

- First release: the nativize skill for React Native, Expo and SwiftUI.
- `scan.mjs`: 17 code-level tells with file, line, fix and a 0-100 score; `--json` and `--min-score` for CI.
- `capture.sh`: default, largest text and dark mode screenshots from an iOS simulator or Android emulator.
- `compare.py`: before and after image from two capture folders.
- Example: an AI-style habit tracker home screen and its nativized version.
